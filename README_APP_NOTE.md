The task table says "app.py / app_v2.py, whichever actually exists" — there
were actually three iterations built over the course of this project
(app.py, app_v2.py, app_v3.py). **app.py in this folder is app_v3.py
renamed** — it's the most complete version, with the four-page structure
(Forecast Overview / Suburb Forecast / Model Accuracy / Data Quality &
Processing) matching the professor's detailed spec, full MAE/RMSE/MAPE/R²/
Directional Accuracy metrics, and a working suburb comparison feature.

Don't also push the earlier app.py/app_v2.py drafts — just this one,
so the repo doesn't look like three competing, unfinished attempts.

`dashboard_demo.html` and `assets/NSW_Dashboard_v2.html` are static
preview-only demos (not real, deployable apps) — useful for quick
screenshots, but `app.py` is the actual working web app.
